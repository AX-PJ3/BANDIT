## 에이전트 경로 (T1)

에이전트는 루트 `CLAUDE.md` "팀 위키 규칙"의 순서대로 움직여요. 코드는 문구와 저장 값만 들고 있어요.

| 파일                   | 내용                                                                                                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/t1/copy.ts`       | T1 문구 (착수 안내 3절 → FigJam "T1 결정 사항 등록" 10/13). 묻기, 아니오, 이유 묻기, ③ 등록될 모습, 취소, ④ 등록 완료. 문구는 여기에만 둬요                 |
| `src/t1/save-input.ts` | 등록하기를 골랐을 때 저장 값. `source: ai_chat`, `aiDetected: false`(임시), `baseVersion`은 `get_standard`의 `currentVersion`, `alwaysOn`·`scope`는 지금 값 |
| `src/t1/preview.ts`    | ③ 등록될 모습 값을 임시 파일(운영체제 임시 폴더 `haribo-t1-pending.json`)에 들고 있는 명령. 에이전트가 터미널로 불러요                                      |
| `src/t1/pending.ts`    | 임시 값 쓰기·읽기·지우기·비교. 시간으로 지우지 않아요                                                                                                       |
| `src/t1/hook-*.ts`     | hooks (`.claude/settings.json`에 등록). 아래 표                                                                                                             |

흐름: 묻기(예/아니오) → 아니오면 작업을 멈추고 사람이 다시 말할 때까지 기다림 / 예면 이유(대화에서 알 수 있으면 정리, 아니면 글로 물음) → `preview.ts` 실행(③은 hook이 띄움) → "이대로 등록할까요?"(등록하기 / 수정하기 / 취소하기) → 등록하기면 저장하고 CHANGELOG에 한 줄 붙이기(위키 파일은 그대로). 선택 창을 Esc로 닫으면 취소하기와 같아요.

| hook              | 언제                        | 하는 일                                                                                              |
| ----------------- | --------------------------- | ---------------------------------------------------------------------------------------------------- |
| `hook-preview.ts` | `preview.ts` 명령 직후      | ③을 꾸며서 띄워요 (청록 제목, 항상 적용은 예일 때만 굵게). hook 글은 도구 **직후**에만 화면에 보여요 |
| `hook-guard.ts`   | `save_standard` 직전        | ③을 보여 준 같은 결정 사항인데 값이 다르면 저장을 막아요. 다른 저장(새로 만들기 등)은 막지 않아요    |
| `hook-clear.ts`   | `save_standard` 직후, 켤 때 | 임시 값을 지워요                                                                                     |

안전장치로 `.claude/settings.json`의 `permissions.ask`에 `save_standard`와 `revert`를 넣어, 저장하기 전에 Claude Code가 한 번 더 허락을 받아요. auto mode에서도 뜨고, 허락 창에서 "Yes, and don't ask again"을 골라도 다음에 다시 물어요 (10/13 시험).

아직 없는 것: ③의 이슈 표와 ④의 "확인할 변경을 보낸 이슈 수"(이슈를 읽는 도구가 필요해요), ④를 hooks로 띄우기, `detect.ask.rollback-if-applied`(이미 코드에 들어간 값 되돌리기), `detect.ask.direct-request-skip-warn`(직접 바꿔 달라는 요청).
