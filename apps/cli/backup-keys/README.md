# 백업 공개 키

매일 백업(`.github/workflows/backup.yml`)은 이 폴더의 공개 키(`*.pub.pem`)로 백업 파일을 잠가요. 여기 있는 키 주인이면 누구든 그날 백업을 열 수 있어요.

- **공개 키만 둬요.** 개인 키(`*.key.pem`)는 절대 올리지 않아요. 개인 키는 `sil backup-key`가 내 컴퓨터의 `~/.haribo/backup/`에 만들어요.
- **두 명 이상 둬요.** 한 사람이 개인 키를 잃어도 다른 사람이 열 수 있어요.
- **키 더하기:** `pnpm sil backup-key <이름>`을 실행하고, 생긴 `<이름>.pub.pem`을 PR로 올려요. 머지된 다음 날 백업부터 그 키로도 잠겨요.
- **키 빼기:** 파일을 지우는 PR을 올려요. 이미 그 키로 잠근 지난 백업은 그대로 그 키로 열려요.

자세한 절차는 `docs/백업과-되살리기.md`에 있어요.
