# haribo MCP 등록 안내

Oct 13, 2026 · @kangjeongmin

## haribo가 뭔가요

haribo는 팀 위키의 결정 사항을 Claude Code 대화 안에서 바로 찾고 저장하게 해 주는 MCP 서버예요(MCP는 Claude에 도구를 붙이는 연결 방식이에요). 한 번만 등록하면 어느 폴더에서 Claude Code를 켜도 쓸 수 있어요.

| 이렇게 말하면                     | Claude가 하는 일                            |
| --------------------------------- | ------------------------------------------- |
| "haribo 서버 ping 해 줘"          | 서버 연결 상태와 내 이름 확인               |
| "쿠폰 관련 결정 사항 찾아 줘"     | 낱말, 영역, 코드 경로로 결정 사항 찾기      |
| "app.notify.title-length 보여 줘" | 결정 사항 하나의 최신 내용과 바뀐 기록 보기 |
| 작업 중 사람에게 물어 정한 것     | 새 결정 사항이나 새 버전으로 저장           |

Claude Code를 켤 때마다 항상 적용되는 결정 사항이 대화 맥락에 자동으로 들어가요.

### 준비물

- Claude Code: 터미널이나 데스크톱 앱의 Code 탭
- 팀 토큰: 정민님에게 Slack DM으로 받아요. 채널, 저장소, 문서에는 올리지 않아요.
- 서버 주소: 팀 토큰과 함께 정민님에게 Slack DM으로 받아요. 주소는 `/mcp`로 끝나요.

haribo 저장소를 받아 둔 개발자는 방법 1, 그 밖의 팀원은 방법 2로 등록해요.

## 방법 1: 저장소를 받은 팀원

저장소가 있으면 `pnpm mcp:register` 한 줄로 등록해요. 이름 바꾸기와 등록 명령은 스크립트가 알아서 만들어요. 처음이면 Node 24.18을 맞추고 `pnpm install`부터 해요.

**1단계.** 저장소 맨 위 폴더의 `.env`에 두 줄을 넣어요. `.env`가 없으면 `pnpm onboard`가 만들어 줘요.

```
SIL_MCP_URL=<서버 주소>
SIL_MCP_TOKEN=<팀 토큰>
```

**2단계 (선택).** 서버가 정상인지 먼저 봐요. "✔ MCP 서버가 HTTP로 답해요"가 나오면 돼요.

```bash
pnpm mcp:check --url <서버 주소>
```

**3단계.** 등록해요. `--user` 뒤에는 Linear 이슈 담당자로 쓰는 내 이름을 그대로 넣어요.

```bash
pnpm mcp:register --user 이름
```

`--user`를 빼면 `git config user.name`을 이름으로 써요. 이미 `haribo`가 등록돼 있으면 등록하지 않고 지우는 명령을 알려 줘요.

## 방법 2: 저장소 없이 등록

디자이너, PM, QA, 다른 팀은 명령 두 개면 끝나요. HTTP 헤더에는 한글을 그대로 넣을 수 없어서, 이름을 퍼센트 인코딩(한글을 `%EB%B6%80…` 같은 글자로 바꾸는 것)해서 넣어요.

**1단계.** 내 이름을 바꿔요. 아래 중 하나를 골라 `이름` 자리에 내 이름을 넣고 실행해요. 세 가지 모두 `이름` → `%EC%9D%B4%EB%A6%84`처럼 같은 값이 나와요.

| 컴퓨터                 | 명령                                                                 |
| ---------------------- | -------------------------------------------------------------------- |
| Windows (PowerShell)   | `[uri]::EscapeDataString('이름')`                                    |
| Mac (터미널)           | `python3 -c "import urllib.parse;print(urllib.parse.quote('이름'))"` |
| Node가 있으면 어디서나 | `node -e "console.log(encodeURIComponent('이름'))"`                  |

**2단계.** 서버 주소, 팀 토큰, 1단계에서 나온 값을 넣고 한 줄로 등록해요. `<` `>`는 지우고 넣어요.

```bash
claude mcp add --transport http --scope user haribo <서버 주소> --header "Authorization: Bearer <팀 토큰>" --header "X-Sil-User: <인코딩한 이름>"
```

`--scope user`로 등록해서, 어느 폴더에서 Claude Code를 켜도 haribo가 보여요.

## 등록 확인

Claude Code를 새로 켜서 ping으로 내 이름이 나오면 끝이에요.

1. Claude Code를 **새로** 켜요. 이미 켜 둔 창에는 반영되지 않아요. 데스크톱 앱이면 새 세션을 열어요.
2. 연결을 봐요. 터미널 Claude Code에서는 `/mcp`에서 `haribo`가 `connected`인지, 어디서나 `claude mcp get haribo`에서 `Connected`가 나오는지 봐요.
3. "haribo 서버 ping 해 줘"라고 말해요. 서버와 DB 연결, 그리고 내 이름이 제대로 나와야 해요.
4. "쿠폰 관련 결정 사항 찾아 줘"처럼 말해 써 봐요.

`claude mcp get haribo`는 팀 토큰도 화면에 그대로 보여 줘요. 화면을 공유하는 중이면 실행하지 않아요.

## 꼭 지킬 것

- **주소 끝의 `/mcp`를 빼지 않아요.** 빠지면 연결되지 않아요.
- **이름은 Linear 이슈 담당자 이름과 똑같이 써요.** 이 이름이 결정 사항을 "고친 사람"으로 남고, 바꾼 본인에게는 알리지 않는 규칙도 이 이름으로 맞춰요.
- **팀 토큰은 공유하지 않아요.** 채널, 저장소, 문서, 화면 공유에 남기지 않아요. 새었다고 생각되면 바로 정민님에게 알려요.
- **저장한 결정 사항은 지울 수 없어요.** 저장과 되돌리기는 팀 DB에 바로 쓰여요. 시험 삼아 저장하지 말고, 써 볼 때는 찾기와 보기만 해요.
- **10/12 전에 `sil`이라는 이름으로 등록했다면 지우고 다시 등록해요.** 그대로 두면 같은 도구가 두 번 보여요.

```bash
claude mcp remove sil --scope user
```

## 알아 두면 좋은 것

- claude.ai 설정의 커넥터 화면에는 haribo가 안 보여요. Claude Code 설정에 등록되기 때문이고 정상이에요. 그래서 claude.ai 웹과 모바일에서는 쓸 수 없어요.
- Claude Code를 켤 때 "확인할 변경"을 먼저 보여 주고 답을 받는 기능은 아직 없어요(SIL-28, SIL-67). 지금은 결정 사항을 찾고, 보고, 저장하는 도구만 있어요.

## 막히면

| 이럴 때                                       | 이렇게 해요                                                                                                                   |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `/mcp`에 haribo가 없어요                      | Claude Code를 새로 켰는지, `claude mcp list`에 haribo가 있는지 봐요.                                                          |
| `Failed`나 `Needs authentication`이 나와요    | 주소 끝에 `/mcp`가 있는지, 토큰을 `<` `>` 없이 넣었는지 봐요. `claude mcp remove haribo --scope user`로 지우고 다시 등록해요. |
| ping에 내 이름이 이상하게 나와요              | 이름을 인코딩하지 않고 넣었거나 다른 이름을 넣었어요. 지우고 다시 등록해요.                                                   |
| `pnpm mcp:register`가 이미 등록돼 있다고 해요 | 알려 준 `claude mcp remove haribo --scope user`를 실행하고 다시 등록해요.                                                     |
| `pnpm mcp:register`가 팀 토큰이 없다고 해요   | `.env`의 `SIL_MCP_TOKEN`을 채워요.                                                                                            |
| 같은 도구가 두 번 보여요                      | 예전 `sil` 등록을 지워요.                                                                                                     |
| 그래도 안 돼요                                | 정민님에게 `claude mcp list` 결과를 보내요. 토큰이 보이는 `claude mcp get` 결과는 보내지 않아요.                              |
