# 실행 화면 모음 · 팀 피드백 요청 (2026-10-11)

> **무엇인가요:** haribo의 기능을 실제로 실행하고, 화면을 단계마다 찍어 모았어요. 기능이 기대대로 도는지 팀원이 직접 보고 의견을 주시면 좋겠어요.
>
> **피드백은 이렇게 주세요:** [9절 "피드백 받고 싶은 점"](#9-피드백-받고-싶은-점)에 질문을 모아 두었어요. 번호를 붙여 Linear 댓글이나 PR 리뷰로 답해 주세요. 그 밖에 이상해 보이는 화면은 그림 번호(예: `27-save-v2`)를 같이 적어 주세요.
>
> **결과:** 찍은 기능은 모두 기대대로 동작했어요. 다만 실제 Supabase와 배포 주소는 아직 없어요. 그래서 그 둘을 대신한 부분은 [10절](#10-이-문서가-보여-주지-못한-것)에 적었어요.
>
> **코드는 아직 올리지 않았어요:** 화면에 나오는 코드(`apps/`, `packages/`, `supabase/`)는 이 저장소에 아직 없는 로컬 작업본이에요. 지금까지 만든 것이 실제로 도는지 먼저 보여 드리고, 코드는 피드백을 반영해 나눠서 올릴게요.

- **터미널 화면(1~7절):** 실제 PowerShell과 Claude Code를 Windows 의사 터미널(ConPTY)에서 실행했어요. 실행 중인 그 순간의 화면(글자와 색)을 그대로 이미지로 옮겼어요. 사람이 키보드로 입력하는 대신 스크립트가 같은 키를 눌렀어요.

  - 글자는 하나도 고치지 않았어요.

### 6-6. 이유를 비우고 저장하면 거절

이유를 빈 문자열로 저장하게 하자 MCP 서버가 "이유(reason)이(가) 비어 있어요. 지어내지 말고 사람에게 물어본 뒤 다시 저장해 주세요"로 거절했어요. 새 버전은 생기지 않았어요 (SIL-65 조건 6). 같은 검사는 DB 함수에도 있어요 (4절 `wiki.test.sql`).

> **10/11 고침 (로컬 코드, 아직 저장소에 올리지 않음):** 전에는 칸을 빈 문자열로 넣을 때만 한국어 문구가 나오고, 칸을 아예 빼면 "expected string, received undefined" 같은 영어 기본 문구가 나왔어요. 이제는 칸을 빼도 빠진 칸을 한국어로 한 번에 알려 줘요.
>
> - `save_standard`: ID, 제목, 값, 이유, 항상 적용, 기준 버전(`baseVersion`)
> - `revert`: 되돌아갈 버전(`toVersion`), 이유
> - 앞머리 "Input validation error: Invalid arguments for tool …"는 MCP SDK가 붙이는 문구라 바꿀 수 없어요. 글자 자리에 숫자를 넣는 것처럼 모양이 틀린 값은 기본 문구 그대로예요.
> - 테스트 2개를 더해 단위 테스트 77개가 통과했어요.

## 7. Claude Code에서 되돌리기 · 정민님 세션

이번에는 Claude Code를 **기본 권한 모드**(`--permission-mode default`)로 켰어요. 도구를 쓰기 전마다 Claude Code가 사람에게 물어요. 화면 아래에는 "manual mode on"으로 보여요. 사람 이름은 "정민"이에요.

![정민 세션 시작](images/live-run/30-jeongmin-start.png)

### 7-1. 권한 확인 창

"v1으로 되돌려 줘"라고 하자 권한 확인 창이 세 번 떴어요. 모두 1번(Yes)을 골랐어요.

1. **기준 읽기(`get_standard`):** 지금 버전을 확인해요.
2. **되돌리기(`revert`):** 넘길 값(대상 버전 1, 지금 버전 2, 이유)과 도구 설명이 보여요.
3. **기준 읽기(`get_standard`):** 되돌린 뒤 기록을 다시 읽어요.

창에 나오는 도구 이름은 "sil — Revert Tool"처럼 영어로 보여요 ([9절](#9-피드백-받고-싶은-점) 1번).

## 10. 이 문서가 보여 주지 못한 것

- **실제 Supabase가 아니에요.**
  - Claude Code 세션은 이 PC의 임시 PostgreSQL에 공용 키와 같은 권한으로 붙였어요.
  - 웹 앱의 DB 연결은 PostgREST처럼 응답하는 시험 서버로 확인했어요.
  - supabase-js ↔ Supabase 실제 호출은 프로젝트를 만든 뒤 다시 확인해야 해요.
- **배포 주소가 없어요.** 웹 앱과 MCP 서버를 올릴 곳을 아직 정하지 않았어요. PWA 설치는 `localhost`에서 확인했고, 실제로는 HTTPS 주소가 필요해요. "앱으로 설치"를 눌러 실제로 설치한 화면은 브라우저 바깥 창이라 찍지 못했어요.
- **아직 만들지 않은 기능은 찍을 수 없었어요.** 확인할 변경 만들기(조건 9), 터미널 알림(`sil brief`), 앱 알림, 화면 세 칸이 그래요.
- **팀원 PC 등록은 하지 않았어요.** 팀원 PC에서 하는 `pnpm mcp:register`는 이 PC의 Claude Code 설정을 바꾸는 일이라 돌리지 않았어요. 대신 작업 폴더의 `.mcp.json`으로 같은 연결을 만들었어요.
