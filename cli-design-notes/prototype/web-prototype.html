SIL-68 · v2 · 10/13

터미널 알림 v2 프로토타입

알림 글은 notice.py가 만든 hooks 글을 그대로 썼고, 언제 무엇이 뜨는지도 시안 hooks와 같은 규칙이에요. 아래 터미널에 직접 입력하고 골라 보세요.

조작

터미널

해 볼 것

  1. 아무 작업이나 입력해요.
  2. 질문에 답해요. ↑↓·숫자·클릭으로 고르고 Enter. 보기 대신 직접 써 봐도 돼요.
  3. 중간에 Esc로 닫아요. Claude가 작업을 마치면 입력 칸 바로 위에 한 줄이 떠요.
  4. 다시 불러요.
  5. "Claude Code 다시 켜기"를 누르면 남은 변경만 켤 때 알림에 떠요.
  6. 관계있다로 답한 뒤 이슈에 반영했다고 등록해요.

이슈 반영 (10/15)

  • 관계있다로 답한 변경 중 아직 등록하지 않은 것만 대상이에요. 관계없다로 답했거나 답하지 않은 변경은 등록할 수 없어요.
  • 1건이어도 바로 등록하지 않고 "이 변경을 이슈에 반영했나요?"로 한 번 더 확인해요.
  • 이슈 반영할 변경이 남아 있으면 다음 작업을 입력할 때 한 줄로 알려요. 한 세션에 한 번만 띄우고, 이미 이슈 반영을 입력한 세션에는 띄우지 않아요. 다시 궁금하면 Claude에게 물어보면 돼요.
  • 2건 이상이면 목록을 띄우고 여러 개 고르기로 반영한 것을 골라요. Claude Code의 Submit 탭에서 고른 것을 확인하고 Submit answers로 등록해요. Esc로 닫으면 아무것도 등록하지 않아요.
  • 5건부터는 질문을 나눠 탭으로 띄워요(5건이면 3건 + 2건). 선택 화면은 질문 하나에 보기가 4개까지예요. ←→로 탭을 옮겨요.
  • 바로 해 보려면 위 "변경"에서 이슈 반영 · 관계있다 5건 답함, 3건 답함, 1건 답함 중 하나를 골라요.

v1에서 바뀐 것

  • 켤 때 첫 줄과 닫은 뒤 한 줄 앞에 노란 막대
  • 변경 상세를 위아래 선으로 묶고, 위 선에 1/5 칩과 머리표
  • 제목 끝 태그 (변경) (신규) (되돌림) (폐기)와 상세 줄
  • 닫은 뒤 한 줄은 작업을 입력할 때가 아니라 작업을 마친 뒤

흉내인 것

선택 화면 모양, Claude 글과 작업 내용, 생각하는 시간, Stop says: 머리줄(실제 모양은 확인 전)은 근사예요. 되돌림 예시는 지어낸 것이에요. 답은 이 창에만 남고 저장되지 않아요. 여러 개 고르기 화면 모양(체크 칸, Submit 탭)도 근사예요.
