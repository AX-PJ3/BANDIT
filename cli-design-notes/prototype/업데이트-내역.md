## 10/13 오후 · "잘 모르겠다" 보기 (`a4e8d8b` `fd4b3b9`)

바로 판단하기 어려울 때 고를 보기가 없었다는 사내 테스트 의견(P3, SIL-71)을 반영했어요. 위키 `notify.answer.two-questions` v2와 `notify.answer.unsure-later`(10/12 결정, 커밋 `4898a9b`)를 따라요.

```
⟦ #7 ⟧
이 변경이 내 이슈와 관계가 있나요?
❯ 1. 관계있다      내 이슈 결과물이 이 변경에 맞춰 바뀌어야 해요
  2. 관계없다      내 이슈와는 상관없는 변경이에요
  3. 잘 모르겠다   지금은 판단하기 어려워요. 나중에 답할게요
  4. Type something.

▌ 나중에 답할 수 있게 남겨 두었어요. "결정 사항 확인"으로 다시 볼 수 있어요.
```

## 10/13 15:13 · v2 화면

v1 사내 테스트 피드백(다른 글과 섞여 몰랐다, 무엇이 바뀌었는지 안 들어온다, 다시 돌아오기 어렵다)을 반영했어요.

| 화면               | v1                              | v2                                                                                                                        | 이유                                                                 |
| ------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 켤 때 알림         | `● [영역] 결정 사항이 N건 …`    | 첫 줄 앞에 **노란 막대**, 설명 줄은 막대 없이                                                                             | `●`가 Claude 답의 점과 같아 Claude 말처럼 읽혔어요 (P1·P2)           |
| 변경 상세 묶음     | 진행 문장 + `1/3` 칩, 구분 없음 | **위아래 선**으로 묶고 위 선에 머리표 `-- [1/5] 작업 전에 확인할 변경이 5건 있어요 ---`. 칩은 왼쪽, 문장은 회색 보통 굵기 | 다른 글과 섞이지 않게 단락을 나눠요                                  |
| 제목               | 기본 글자색 굵게                | **청록 굵게**                                                                                                             | "읽을 정보"라는 중립 색. 노랑(봐야 할 것)·초록(완료)과 겹치지 않아요 |
| 종류 태그          | `(신규)` `(폐기)`만             | `(변경)` `(신규)` `(되돌림)` `(폐기)` 네 가지                                                                             | 모든 변경의 종류가 제목 끝에서 보여요                                |
| 바뀐 내용          | `변경  40자 ⭢ 32자`만           | 아래에 **`상세`** = 결정 사항의 값 전체(두 줄까지). 신규는 상세만, 폐기는 없어진 값만(회색)                               | 변경 줄만으로는 무엇이 바뀌었는지 몰랐어요 (P2)                      |
| 기록 줄            | `✓`만 초록                      | **`✓ 기록했어요`** 초록                                                                                                   | 완료를 한눈에                                                        |
| 닫은 뒤 한 줄      | 작업을 **입력할 때** 띄움       | Claude가 작업을 **마친 뒤 입력 칸 바로 위**에 띄움(Stop hooks). 노란 막대 + `"결정 사항 확인"` 노란 굵게                  | 작업 결과에 밀려 올라가 못 봤어요 (P1·P3)                            |
| 닫아도 된다는 안내 | 없음                            | 넣지 않음                                                                                                                 | 테스트 진행 관련 피드백이라 뺐어요                                   |

함께 넣은 시험 옵션(기본은 그대로):

| 켜는 법                         | 보는 것                                                                                     |
| ------------------------------- | ------------------------------------------------------------------------------------------- |
| `NOTICE_DATA=changes-v2 claude` | 태그 네 가지와 크게 바뀐 변경을 한 세션에서 차례로 (5건, 되돌림은 지어낸 예시)              |
| `NOTICE_LAYOUT=impact claude`   | 상세를 추천 순서(제목 → 영향 → 이전·이후 비교 → 이유)로 배치한 시안                         |
| `NOTICE_TITLE_COLOR=35 claude`  | 제목 색 바꿔 보기 (기본 36 청록)                                                            |
| `NOTICE_COLS=auto claude`       | 화면 너비를 터미널 너비에 맞춰 보기 (Claude Code가 hooks에 넘기는 `COLUMNS` 사용, 40~100칸) |

웹 워킹 프로토타입(`web-prototype.py` → `web-prototype.html`)도 이때 만들었어요. notice.py가 만든 hooks 글을 그대로 담고, 입력·선택·Esc·다시 부르기를 hooks와 같은 규칙으로 돌려요.
