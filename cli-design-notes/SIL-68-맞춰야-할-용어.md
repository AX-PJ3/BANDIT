### 용어-4. 세는 단위 — "건" / "개"

- 착수 문서 "변경 개수", 정민님 시험 문서 "3개", 실행-화면 문서 "0건", 터미널 시안 "2건"
- **제안**: "변경"을 셀 때는 "건"이 자연스러워요. 앱 숫자 배지와 문장에서 같은 단위를 써요(T2-첫줄 결정기록 6장).

### 용어-5. 바꾼 사람 — "부건" / "부건님"

- 착수 문서 5장 "이름만", 터미널 시안 `부건님이 오후 2:13에 변경했어요.`(문장이라 "님", 흐름 결정기록 5-6)
- **제안**: "문장 안에서는 님, 칸 안에서는 이름만"으로 맞춰요.

### 용어-6. "바꾸다" / "변경하다"

- 착수 문서 "누가 언제 **바꿨는지**", 출처 "AI 대화에서 **바꿈**"
- 터미널 시안 `**변경했어요**`, `**변경되었어요**`
- "확인할 변경"은 이름이라 그대로 두고, 문장 속 동사만 맞춰요.
- **제안**: "바꿨어요 / 바뀌었어요"로 맞추면 `copy.explain.plain-words`와도 맞아요.

### 용어-7. 이슈 줄 이름표

- 착수 문서 T3·A3 "내 이슈", 위키 `notify.terminal.show-fields` "영향받는 이슈", 예전 Spec "영향", 터미널 시안 `이슈`
- **제안**: 터미널은 칸이 좁아 `이슈`로 두고, 앱은 "내 이슈"를 써도 뜻이 같아요. 확인만 해요.

### 용어-8. "작업"이 가리키는 것

- 위키 `copy.term.issue`: 이슈를 "작업"이라고 부르지 않아요.
- 터미널 시안의 "작업"은 대부분 **Claude Code에서 지금 하려는 일**이에요(`작업 전에`, `작업을 시작하면`).
- **예외**: "왜 관계없나요?" 보기 중 `내 작업 범위가 아니에요`, `바뀐 부분은 내 작업에 안 쓰여요`는 이슈를 가리켜요. 같은 질문의 다른 보기는 `내 이슈와 연결이 잘못됐어요`라서 한 화면에 섞여요.
- 위키 `notify.answer.two-questions`도 "이 변경이 **내 작업**에 영향을 주는지"로 적었어요(시안 질문은 `내 이슈와 관계가 있나요?`).
- **제안**: 이유 보기를 `내 이슈 범위가 아니에요`, `바뀐 부분은 내 이슈에 안 쓰여요`로 고쳐요.

### 용어-9. 답하기 문구 (터미널 ↔ 앱)

| 무엇                    | 터미널 시안                                                                                                         | 앱                         |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| 알았나 설명             | `오늘 알림을 보기 전에 알고 있었어요`                                                                               | 아직 없음                  |
| 관계없는 이유           | 보기 3개 + 직접 입력                                                                                                | 착수 문서는 입력란 1개     |
| 기록 줄                 | `✓ 기록했어요  #5 · 관계있다 · 몰랐다`                                                                              | A4 "내가 한 답, 답한 시각" |
| 관계 보기 "잘 모르겠다" | 보기 `잘 모르겠다` (설명 `지금은 판단하기 어려워요. 나중에 답할게요`), 고른 뒤 `나중에 답할 수 있게 남겨 두었어요.` | 버튼 이름 확인 필요        |

**신지님 확인 (10/13)**: 위키 `notify.answer.two-questions` v2로 관계 보기에 "잘 모르겠다"가 생겼어요. 앱 "나에게 온 변경"의 버튼도 같은 말 `잘 모르겠다`로 쓸지, 고른 뒤 안내 `나중에 답할 수 있게 남겨 두었어요.`도 앱에서 같은 말로 쓸지 확인해요. 고른 변경은 답으로 기록하지 않고 확인할 변경으로 남아서 앱 목록에도 그대로 보여요(`notify.answer.unsure-later`).

### 용어-10. 확인할 변경 상태 이름

- 착수 문서 2장 "새 버전으로 대체됨", 5장·7장 "대체됨"
- SIL-73 저장 값: 대기 / 답함 / 대체됨 / 자동 닫힘. 화면에는 대기·답함·대체됨만 나와요.
- 위키 `data.pending.status-values`: 대기 / 답함 / 새 버전으로 대체됨 / **답 취소**. 답 취소는 폐기됐고 자동 닫힘은 새로 생겼는데, SIL-64에서 이 결정 사항은 고치지 않았어요.
- **제안**: 상태 이름은 "대체됨", 설명이 필요한 곳에만 "새 버전으로 대체됨". 위키가 빠진 것은 호윤님께 알려 드려요. 색은 시각-7.

### 시각-1. 종류 태그 색

### 시각-2. 폐기·되돌림을 앱에 그릴지

- 앱 상태 6가지(빈 화면, 알림 꺼짐, 사람이 바꿈, PR에서 찾음, 새로 생김, 대체됨)에 폐기·되돌림이 없어요.
- SIL-64 변경 22개 중 폐기가 9개, 신규가 2개예요. 데모 이후 실제 변경에는 자주 나와요.
- **제안**: 앱에도 태그로 보여 줘요. 폐기는 "지금 값"이 없으니 이전 값만 보여 주는 모양이 필요해요(터미널은 `결정 사항을 폐기했어요` + 이전 줄).

### 시각-3. 출처 "AI가 찾음" 표시

- 터미널: `출처  PR · AI가 찾음`처럼 꾸밈 없는 글자. 청록·보라 칩은 버렸어요(흐름 결정기록 9장 30번).
- 앱: 착수 문서는 "AI가 찾아낸 변경이라는 표시가 필요"라고만 해요.
- **제안**: 글자 또는 색 없는 배지. 낱말은 용어-13.

### 시각-5. 끝난 것 — 초록

- 터미널: `[완료]` 이슈, `✓ 기록했어요`, `✓ 확인할 변경이 없어요`
- **제안**: 앱 A4, 빈 화면, 이슈 완료도 초록. 다만 초록이 "이슈 완료"와 "답 기록됨" 두 뜻을 함께 써요. 앱에서 한 화면에 둘이 나오면 구분이 필요해요.

### 시각-6. 오류 — 빨강

- 터미널: 빨강을 쓰지 않아요(취소선 시안도 버렸어요). 연결 실패 화면은 아직 없어요.
- 정민님 웹 앱: 연결 실패를 빨간 글씨로 보여 줘요(`notify.error.not-empty`).
- **제안**: 빨강은 오류에만 써요. 터미널 연결 실패 화면을 만들 때도 같은 뜻으로 써요.

### 시각-7. 대체됨 — 흐리게

- 터미널: 묻던 중 또 바뀐 경우를 어떻게 보일지 아직 없어요(민수-B1).
- 앱: 답한 쪽에 "눈에 띄지 않게".
- **제안**: 앱은 흐리게. 터미널은 민수님 답을 받은 뒤 같은 뜻(흐림)으로 정해요. 이름은 용어-10.

### 시각-8. 답 — 색 없음

- 터미널: `✓ 기록했어요  #5 · 관계있다 · 몰랐다`에서 답에는 색이 없어요.
- **제안**: 앱도 색 없이. "몰랐다"가 빨강이면 잘못 답한 것처럼 읽혀서, 핵심 지표인 "몰랐다" 답이 줄어들 수 있어요.

## C. 강조와 배치

### 시각-9. 바뀐 부분 강조

- 터미널: 이전 낱말 흐리게 `⭢` 새 낱말 굵게. 배경색 없음(10/12 형광펜에서 바꿈). "지금" 줄은 뺐어요.
- 앱: A2 "이전 → 지금", A3 이전 값 → 지금 값.
- **제안**: 이전은 연하게, 새 값은 진하게로 같은 방식을 써요. 화살표 기호(`⭢` / `→`)도 맞춰요. 앱은 형광펜을 쓸 수 있지만 터미널은 뺐다는 점을 알고 정해요. 문구는 용어-11.

### 시각-10. 몇 번째

- 터미널: 2건 이상일 때 제목 위에 반전 칩 `⟦ 1/2 ⟧`. 터미널에 남은 유일한 칩이에요.
- **제안**: 앱 A3에 순서 표시가 있다면 "1/2" 같은 숫자 모양으로 맞춰요.

### 시각-11. 영역

- 터미널: `● [app] 결정 사항이 1건 변경되었어요.`, 상세 제목 `[app] 제목`. 영어 코드 그대로예요(T2-첫줄 결정기록).
- 착수 문서의 "화면에 들어가는 데이터"에는 영역이 없어요.
- **제안**: 앱에서 영역을 보여 줄지, 보여 준다면 같은 영어 코드인지 정해요. 결정 사항 ID(`app.notify.title-length`)를 숨길지와 함께 정하면 돼요.

### 시각-12. OS 알림(A1)은 글자로

- 웹 알림은 제목·본문·아이콘만 정할 수 있어서 **색을 못 써요**.
- **제안**: 종류·출처를 글자로 넣어요. 그래서 터미널의 글자 태그 `(폐기)` `(신규)`가 앱과 터미널의 공통 분모예요.
