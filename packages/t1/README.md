# @sil/t1

T1(결정 사항과 다르면 먼저 묻기)의 화면 모양, 문구, 저장 값이에요. 담당: **경하님** (문구는 **부건님**, SIL-66)

MCP 서버(`show_standard_check` 도구와 T1 hooks)가 가져다 써서 `apps/detect/src/t1/`에서 옮겼어요 (BDT-108, D49). 화면은 저장하지 않고 글자만 만들어요. ③ 받는 이슈만 팀 DB를 읽어요.

| 파일                | 내용                                                                                                                                                                                                                                                             |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/copy.ts`       | T1 문구 (착수 안내 3절 → FigJam "T1 결정 사항 등록" 10/13). 다른 결정 사항 화면(`conflicts`, 경우 1·2), 묻기, 아니요, 이유 묻기, ③ 등록될 모습, 취소, ④ 등록 완료, 직접 요청(`direct`), 되돌림 화면(`conflicts.revert`, 부건님 시안 10/16). 문구는 여기에만 둬요 |
| `src/save-input.ts` | 등록하기를 골랐을 때 저장 값. `source: ai_chat`, `aiDetected`는 에이전트가 알아챘으면 `true`·직접 요청이면 `false`(D61), `baseVersion`은 `get_standard`의 `currentVersion`, `alwaysOn`·`scope`는 지금 값. 새 결정 사항은 `buildT1NewSaveInput`(`baseVersion: 0`) |
| `src/screens.ts`    | hooks가 띄우는 화면 모양(③ 등록될 모습, 다른 결정 사항 화면). 부건님 프로토타입 "T1 결정 사항 등록"(10/14)을 옮겼어요. 칸 계산은 `text.ts`                                                                                                                       |
| `src/issues.ts`     | ③ 이슈 표에 넣을 받는 이슈를 core `listIssues()`로 팀 DB에서 읽어요(팀원 `.env`의 Supabase 주소·공용 키). 알리기와 같은 규칙(담당자 있음, 바꾼 본인 뺌). 못 읽으면 표 칸 이름만 보여요                                                                           |
| `src/text.ts`       | 화면 칸 계산(한글·이모지는 두 칸), 줄 나누기와 자르기                                                                                                                                                                                                            |

테스트는 `src/t1.test.ts`예요 (`pnpm test`). hooks 테스트는 `apps/mcp-server/src/hooks/t1-hooks.test.ts`예요.
