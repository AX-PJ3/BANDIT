# 데스크톱 앱 화면 (app)

> **영역 요약:** 데스크톱 앱 화면, 앱 알림, 설치
> **관련 문서:** 스펙: 기준 모으기 "데스크톱 앱", 스펙: 담당자에게 알리기 "앱 알림"
> **DRI:** 신지님 (데이터: 정민님)

### app.platform.mac-windows
- 제목: 앱은 웹 앱으로 만들고 PWA로 설치할 수 있게 한다
- 값: 앱은 웹 앱으로 만들고 PWA(설치할 수 있는 웹 앱)로 설치할 수 있게 한다
- 이유: 팀원과 다른 팀의 운영체제가 섞여 있고, 웹 앱은 운영체제별 설치 파일이 필요 없다
- 적용 범위: 코드: packages/app/** / 코드: .github/workflows/release.yml
- 근거: 10/8 경하님·정민님 결정 · Linear SIL-64
- 항상 적용: 아니오
- 상태: 사용
- 버전: 2

### app.screen.inbox-first
- 제목: 앱에서 꼭 만들 화면은 "나에게 온 변경" 하나다
- 값: 이번 범위에서 꼭 만들 앱 화면은 나에게 온 변경과 답하기이며, 위키 화면과 지표 화면은 시간이 되면 만든다
- 이유: 주 지표를 모으는 데 필요한 화면은 답하는 화면뿐이다
- 적용 범위: 코드: packages/app/src/** / 화면: 나에게 온 변경
- 근거: 스펙: 기준 모으기 "데스크톱 앱" · MVP 범위
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### app.notify.realtime
- 제목: 웹 앱이 열려 있으면 확인할 변경을 바로 알림으로 띄운다
- 값: 웹 앱 창이 열려 있으면 데이터베이스의 실시간 변경을 받아 확인할 변경이 생기는 즉시 운영체제 알림을 띄우고, 웹 푸시는 10/13 이후로 미룬다
- 이유: 디자이너는 Claude Code를 자주 켜지 않아 터미널 알림만으로는 늦다
- 적용 범위: 코드: packages/app/src/notify/**
- 근거: 착수 안내 "하지 않는 것과 정해진 결정" · Linear SIL-64
- 항상 적용: 아니오
- 상태: 사용
- 버전: 2

### app.notify.click-to-inbox
- 제목: 앱 알림을 누르면 "나에게 온 변경" 화면으로 간다
- 값: 운영체제 알림을 누르면 앱의 나에게 온 변경 화면이 열리고 해당 변경이 선택된 상태가 된다
- 이유: 알림에서 답하기까지 한 번에 가야 확인 시간이 줄어든다
- 적용 범위: 코드: packages/app/src/notify/** / 화면: 나에게 온 변경
- 근거: Linear SIL-42
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### app.notify.title-length
- 제목: 앱 알림 제목은 40자 이하다
- 값: Mac과 Windows 알림 창에 뜨는 제목은 공백 포함 40자 이하로 쓴다
- 이유: 40자를 넘으면 Mac 알림 창에서 잘린다
- 적용 범위: 코드: packages/app/src/notify/** / 화면: 앱 알림
- 근거: Linear SIL-43
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### app.notify.windows-id
- 제목: Windows 앱에는 앱 고유 ID를 설정한다
- 값: Windows에서 알림이 뜨도록 앱 고유 ID(AppUserModelID)를 설정한다
- 이유: 설정하지 않으면 Windows에서 알림이 뜨지 않는다
- 적용 범위: 코드: packages/app/src/main/**
- 근거: 스펙: 담당자에게 알리기 "앱 알림"
- 항상 적용: 아니오
- 상태: 폐기
- 대체: app.notify.realtime
- 버전: 2

### app.startup.auto-launch
- 제목: 앱은 컴퓨터를 켤 때 자동으로 실행된다
- 값: 앱은 운영체제 시작 시 자동으로 실행되도록 설정한다
- 이유: 앱이 꺼져 있으면 알림을 받을 수 없다
- 적용 범위: 코드: packages/app/src/main/**
- 근거: 스펙: 담당자에게 알리기 "앱 알림"
- 항상 적용: 아니오
- 상태: 폐기
- 대체: app.platform.mac-windows
- 버전: 2

### app.install.unsigned-guide
- 제목: 앱은 정식 인증 없이 배포하고 경고 넘기는 안내를 준다
- 값: 앱은 Apple 개발자 인증과 Windows 코드 서명 없이 배포하고, 처음 열 때 뜨는 경고를 넘기는 방법을 설치 안내에 적는다
- 이유: 인증 절차에 시간이 걸려 일정 안에 끝낼 수 없다
- 적용 범위: 문서: 설치 안내 / 화면: 첫 실행
- 근거: 스펙: 기준 모으기 "데스크톱 앱"
- 항상 적용: 아니오
- 상태: 폐기
