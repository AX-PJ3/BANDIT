# 기능: 담당자에게 알리기 (notify)

> **영역 요약:** 이슈 연결, 영향받는 담당자 찾기, 터미널 알림, 응답, 예외 처리
> **관련 문서:** 스펙: 담당자에게 알리기, PRD-03, PRD-04 기능 3
> **DRI:** 민수님 (디자인: 부건님)

### notify.link.human-confirm
- 제목: 이슈와 기준의 연결은 사람이 확인해야 저장된다
- 값: AI는 관련 기준 후보를 제안만 하고, 사람이 맞다고 한 것만 이슈와 기준 연결로 저장한다
- 이유: 잘못 연결되면 관계없는 사람에게 알림이 가서 관계없다 비율이 올라간다
- 적용 범위: 코드: packages/mcp/src/tools/link_task*
- 근거: MVP 범위 "이슈와 기준 연결"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### notify.link.no-guess
- 제목: 연결이 없는 이슈는 "근거 없음"으로 표시한다
- 값: 도구는 이슈와 기준의 연결을 임의로 만들지 않고, 연결이 없는 이슈는 근거 없음으로 표시한다
- 이유: 추측으로 연결하면 알림이 틀린 사람에게 간다
- 적용 범위: 코드: packages/mcp/src/tools/link_task* / 화면: 요약 화면
- 근거: PRD-04 기능 3 "작업과 기준 연결"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### notify.target.include-done
- 제목: 완료된 이슈의 담당자에게도 알린다
- 값: 바뀐 기준과 이어진 이슈가 완료 상태여도 담당자에게 확인할 변경을 만든다
- 이유: 이미 만든 결과물이 바뀐 기준과 달라졌을 수 있다
- 적용 범위: 코드: packages/mcp/src/tools/notify*

### notify.pending.one-per-issue

- 이유: 이슈 단위로 답을 받아야 어떤 작업이 영향받았는지 셀 수 있다
- 적용 범위: 코드: packages/mcp/src/tools/notify*
