# 데이터 구조 (data)

> **영역 요약:** ID 형식, 기록 형식, 상태 값
> **관련 문서:** 스펙: 기준 모으기 "데이터 구조", 사일로 OKR과 지표
> **DRI:** 정민님

### data.standard.id-format
- 제목: 기준 ID는 영역.주제.규칙 형식이다
- 값: 기준 ID는 영문 소문자·숫자·하이픈으로 된 세 부분을 점으로 이은 형식이며, 한 번 정하면 바꾸지 않는다
- 이유: ID가 바뀌면 이슈 연결과 버전 기록이 끊긴다
- 적용 범위: 코드: packages/core/src/types/** / 코드: scripts/check_wiki.py
- 근거: 스펙: 기준 모으기 "기준 하나의 모양" · 기준 작성 원칙 3
- 항상 적용: 예
- 상태: 사용
- 버전: 1

### data.issue.linear-id
- 제목: 이슈 번호는 Linear 번호를 그대로 쓴다
- 값: 이슈와 기준 연결, 확인할 변경, 응답 기록의 이슈 번호는 Linear 이슈 번호(SIL-12 형식)를 그대로 쓴다
- 이유: 번호를 따로 만들면 Linear와 맞추는 일이 생긴다
- 적용 범위: 코드: packages/core/src/** / 코드: packages/mcp/src/tools/link_task*
- 근거: PRD-05 "기록 양식" · Linear SIL-29
- 항상 적용: 아니오
- 상태: 폐기
- 대체: data.issue.tool-number
- 버전: 2

### data.issue.tool-number
- 제목: 이슈 번호는 이 도구가 붙이는 #번호를 쓴다
- 값: 이슈와 기준 연결, 확인할 변경, 응답 기록의 이슈 번호는 이 도구가 붙이는 #번호(#5 형식)를 쓰고 Linear 이슈 번호와는 상관없다
- 이유: 이 도구는 Linear와 연결하지 않아서 Linear 번호를 따라갈 이유가 없다
- 적용 범위: 코드: packages/core/src/** / 화면: 나에게 온 변경 / 문서: 착수 안내
- 근거: 착수 안내 "하지 않는 것과 정해진 결정" · Linear SIL-79
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### data.response.columns
- 제목: 응답 기록은 정해진 14개 열로 남긴다
- 값: 응답 기록은 기록 시각, 기준 ID, 기준 버전, 바뀐 내용, 바꾼 사람, 근거, 이슈 번호, 담당자, 관계, 알았나, 확인 시간(초), 관계없다 이유, 모르고 계속했다면 다시 할 일, 기록한 방법 열로 남긴다
- 이유: 사람이 기록한 것과 도구가 기록한 것을 같은 표로 합쳐 봐야 한다
- 적용 범위: 코드: packages/cli/src/export/** / 문서: answers.csv
- 근거: 사일로 OKR과 지표 "진짜 도구로 바뀐 뒤"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### data.response.method
- 제목: 응답 기록에는 사람이 적었는지 도구가 적었는지 남긴다
- 값: 응답 기록의 기록한 방법 열에는 사람 또는 도구를 적는다
- 이유: 발표에서 두 경우를 나눠 보여 준다
- 적용 범위: 코드: packages/cli/src/export/**
- 근거: PRD-05 "기록 양식"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### data.response.check-seconds
- 제목: 확인 시간은 알림을 연 순간부터 답할 때까지의 초다
- 값: 확인 시간은 담당자가 알림을 연 순간부터 마지막 답을 고를 때까지 걸린 시간을 초 단위로 잰다
- 이유: 보호 지표 1분 이내를 같은 방식으로 재야 한다
- 적용 범위: 코드: packages/mcp/src/tools/respond* / 코드: packages/cli/src/brief/**
- 근거: PRD-05 "기록 양식"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### data.pending.status-values
- 제목: 확인할 변경의 상태는 네 가지다
- 값: 확인할 변경의 상태는 대기, 답함, 새 버전으로 대체됨, 답 취소 중 하나다
- 이유: 예외 처리 규칙이 이 상태로 동작하고 화면이 상태별로 다르게 보여 준다
- 적용 범위: 코드: packages/core/src/types/** / 화면: 나에게 온 변경
- 근거: PRD-03 예외 1, 2 · 스펙: 담당자에게 알리기
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### data.changelog.format
- 제목: CHANGELOG는 정해진 6칸 형식으로 한 줄씩 남긴다
- 값: CHANGELOG 한 줄은 날짜 시각, 누가, 기준 ID와 버전, 이전 값 → 새 값, 이유, 출처 6칸이며 출처는 코드/AI 대화/Figma/회의/Slack/문서 중 하나다
- 이유: 이 기록이 주 지표와 정확도 실험의 재료가 된다
- 적용 범위: 문서: CHANGELOG.md / 코드: scripts/check_wiki.py
- 근거: v0 도그푸딩 가이드 "CHANGELOG 한 줄"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1
