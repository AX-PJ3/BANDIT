### wiki.read.index-first
- 제목: AI는 목차를 먼저 읽고 필요한 영역만 연다
- 값: AI는 작업 전에 INDEX.md를 읽고, 이번 작업과 관련된 영역 파일만 열며 위키 전체를 읽지 않는다
- 이유: 위키 전체를 넣으면 길이 때문에 정확도가 떨어지고 비용이 늘어난다
- 적용 범위: 문서: INDEX.md / 코드: packages/mcp/src/tools/get_index*
- 근거: 스펙: 기준 모으기 원칙 1, 2
- 항상 적용: 예
- 상태: 사용
- 버전: 1

### wiki.standard.one-rule
- 제목: 기준 하나에는 규칙 하나만 담는다
- 값: 기준의 값은 한 문장으로 끝나야 하며, 규칙이 두 개면 기준을 나눈다
- 이유: 기준이 크면 관계없는 사람에게도 알림이 간다
- 적용 범위: 문서: 기준-작성-원칙.md / 코드: scripts/check_wiki.py
- 근거: 기준 작성 원칙 2 · 스펙: 기준 모으기 원칙 3
- 항상 적용: 예
- 상태: 사용
- 버전: 1

### wiki.standard.required-fields
- 제목: ID·제목·값·이유·항상 적용이 없는 기준은 저장하지 않는다
- 값: 기준을 저장할 때 ID, 제목, 값, 이유, 항상 적용 중 하나라도 비어 있으면 저장을 거절한다
- 이유: v2 데이터 칸 목록에서 꼭 필요한 칸을 5개로 줄였고, 적용 범위와 근거는 비어 있어도 저장할 수 있다
- 적용 범위: 코드: packages/mcp/src/tools/save_standard* / 코드: scripts/check_wiki.py
- 근거: 착수 안내 "데이터 칸 목록 v2" · Linear SIL-64
- 항상 적용: 예
- 상태: 사용
- 버전: 2

### wiki.standard.no-delete
- 제목: 기준은 지우지 않고 폐기로 바꾼다
- 값: 쓰지 않는 기준은 상태를 폐기로 바꾸고 대체한 기준 ID를 적으며, 위키와 데이터베이스에서 삭제하지 않는다
- 이유: 이전 버전이 남아야 되돌리기와 변경 이유 추적이 가능하다
- 적용 범위: 코드: packages/mcp/src/tools/save_standard* / 문서: 기준-작성-원칙.md
- 근거: 스펙: 기준 모으기 원칙 6
- 항상 적용: 예
- 상태: 사용
- 버전: 1

### wiki.version.append-only
- 제목: 기준이 바뀌면 이전 버전을 남기고 새 버전을 쌓는다
- 값: 기준의 값이 바뀌면 이전 버전을 고치지 않고 버전 번호를 1 올린 새 버전을 추가한다
- 이유: 이전 값이 있어야 담당자에게 무엇이 바뀌었는지 보여 줄 수 있다
- 적용 범위: 코드: packages/mcp/src/tools/save_standard* / 코드: packages/core/src/**
- 근거: PRD-04 기능 1 수용 기준
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### wiki.version.record-fields
- 제목: 버전마다 값·이유·바꾼 사람·시간을 남긴다
- 값: 새 버전을 저장할 때 값, 이유, 바꾼 사람, 바꾼 시간, AI가 고쳤는지를 함께 저장하고, 근거와 적용 범위는 있으면 함께 저장한다
- 이유: 알림과 지표가 이 칸들을 그대로 쓴다
- 적용 범위: 코드: packages/core/src/** / 화면: 나에게 온 변경

### wiki.always-on.max-ten
- 제목: 항상 적용되는 기준은 위키 전체에서 10개까지다
- 값: 항상 적용되는 기준은 10개 이하로 유지하고, 세션을 시작할 때 이 기준만 작업 맥락에 넣는다
- 이유: 많이 넣을수록 AI가 중요한 기준을 놓친다
- 적용 범위: 코드: packages/mcp/src/** / 문서: INDEX.md

### wiki.ask.when-missing
- 제목: 관련 기준이 없으면 AI가 사람에게 묻고 새 기준으로 저장한다
- 값: AI가 작업 중 관련 기준을 찾지 못하면 사람에게 묻고, 그 답을 새 기준 버전 1로 저장한다
- 이유: 기준 없이 AI가 임의로 정하면 사람마다 다른 결과물이 나온다
- 적용 범위: 코드: packages/mcp/src/tools/save_standard* / 문서: 각자 CLAUDE.md
- 근거: PRD-04 기능 1 수용 기준 · PRD-03 "기준이 없을 때"
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### wiki.lock.human-first
- 제목: 사람이 잠근 기준은 AI가 고치지 않는다
- 값: 잠금이 예인 기준은 AI가 고치지 않고, 바꿀 필요가 있으면 사람에게 알린다
- 이유: 사람이 직접 정한 내용이 AI 판단보다 우선이다
- 적용 범위: 코드: packages/mcp/src/tools/save_standard* / 코드: packages/detect/src/judge/**
- 근거: PRD-02 "사람 우선" · 스펙: 기준 모으기 원칙 8
- 항상 적용: 아니오
- 상태: 폐기
- 대체: work.wiki.ask-before-change
- 버전: 2

### wiki.revert.new-version
- 제목: 되돌리기도 새 버전으로 저장한다
- 값: 기준을 이전 값으로 되돌리면 이전 버전을 복원하지 않고, 이전 값을 담은 새 버전을 추가한다
- 이유: 되돌린 사실도 담당자에게 알려야 하고 기록이 끊기면 안 된다
- 적용 범위: 코드: packages/mcp/src/tools/revert* / 코드: packages/cli/src/revert/**
- 근거: PRD-02 "되돌리기" · PRD-04 기능 1
- 항상 적용: 아니오
- 상태: 사용
- 버전: 1

### wiki.backup.daily
