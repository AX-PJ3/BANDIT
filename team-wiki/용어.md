# 용어

> 이 파일은 기준이 아니라 용어집이에요. 기준 ID를 붙이지 않아요. 말을 바꾸는 규칙은 문구.md의 copy.term.* 기준에 있어요.

> **이 문서는** 팀 안에서 같은 것을 같은 말로 부르기 위해 만들었어요. 코드의 이름은 오른쪽 영어 이름을 써요.

## 제품 용어

| 우리가 쓰는 말 | 뜻 | 쓰지 않는 말 | 코드 이름 |
|---|---|---|---|
| 팀 위키 | 팀의 기준을 모아 둔 곳. 사람과 AI가 모두 봐요 | 공유 저장소, 결정 사항 저장소 | `wiki` |
| 기준 | 팀 위키에 있는 규칙 하나. 한 문장으로 끝나요 | 결정 사항, 스펙, RULE | `standard` |
| 영역 | 기준을 묶는 큰 분류. 예: 주문, 결제, 화면 공통 | 카테고리 | `area` |
| 적용 범위 | 기준이 적용되는 코드 경로, API, 화면 | - | `scope` |
| 항상 적용되는 기준 | 모든 작업에 넣는 기준. 최대 10개 | 지속되는 제약 조건 | `always_on` |
| 기준 버전 | 기준이 바뀔 때마다 하나씩 올라가는 번호 | - | `version` |
| 근거 | 기준이 바뀐 증거. 코드 변경, 대화, Figma 프레임 | 출처 | `evidence` |
| 폐기 | 더 이상 쓰지 않는 기준. 지우지 않고 표시만 해요 | 삭제 | `deprecated` |
| 잠금 | 사람이 잠근 기준은 AI가 고치지 못해요 | - | `locked` |
| 이슈 | 이 도구가 갖고 있는 작업 목록의 한 건. Linear 이슈와는 별개예요 | 태스크, 작업 | `issue` |
| 이슈와 기준 연결 | "이 이슈는 이 기준을 따른다"는 기록 | 명시 연결 | `issue_standard` |
| 확인할 변경 | 아직 확인하지 않은 바뀐 기준. 이슈마다 하나씩 생겨요 | 확인 대기 | `pending_check` |
| 관계있다 / 관계없다 | 담당자가 "이 변경이 내 일에 영향을 주는지" 답한 것. 기준을 승인하는 게 아니에요 | 수락 / 거절 | `affected` |
| 알았다 / 몰랐다 | "관계있다"고 답할 때 미리 알았는지 함께 답한 것 | - | `known` |
| 되돌리기 | 기준을 이전 버전으로 돌리는 것. 되돌린 것도 새 버전으로 남아요 | 원복, revert | `revert` |
| 충돌 | 같은 버전의 기준을 두 사람이 동시에 다르게 바꾼 상황 | - | `conflict` |

## 기술 용어

| 말 | 뜻 |
|---|---|
| MCP 서버 | Claude Code가 켜질 때 함께 켜지는 작은 프로그램. AI가 팀 위키를 읽고 쓸 수 있게 이어 줘요 |
| hooks | Claude Code가 켜지거나 질문을 받을 때 자동으로 실행되는 기능. 알림을 띄울 때 써요 |
| GitHub Actions | 코드가 반영될 때 자동으로 돌아가는 작업. 바뀐 기준을 찾을 때 써요 |
| Supabase | 팀 위키와 기록을 저장하는 공용 데이터베이스 |
| Electron | Mac과 Windows 데스크톱 앱을 한 번에 만드는 도구 |

## 일하는 방식 용어 (토스에서 쓰는 말)

| 말 | 뜻 |
|---|---|
| 사일로 | 여러 직군이 한 목표를 위해 모인 작은 팀 |
| DRI | 맡은 일의 최종 결정권과 책임을 가진 한 사람 |
| 주 지표 / 보호 지표 | 올리고 싶은 숫자 / 나빠지면 안 되는 숫자. 보호 지표는 가드레일이라고도 해요 |
| 위클리 | 주 단위로 모여 이번 주에 풀 문제를 정하는 모임 |
| 스펙 리뷰 | 만들 것의 세부 내용을 함께 보고 질문과 변경사항을 정리하는 모임 |
| Metric Review | 숫자를 함께 보는 모임 |
| 유저 무물 런치 | 점심시간에 사용자를 만나 이야기를 듣는 모임 |
| 러닝 쉐어 | 배운 점을 발표하고 나누는 것 |

## 쓰지 않는 말

- **수락 / 거절:** 기준을 승인하는 것처럼 들려요. "관계있다 / 관계없다"를 써요.
- **결정 사항:** "기준"과 섞여요. 회의에서 정한 일은 그냥 "결정"이라고 해요.
- **서비스 이름:** 아직 정하지 않았어요. 정하기 전까지는 "이 도구"라고 불러요.
